# Enterprise Sales Analytics Dashboard

## Project Overview
This project is an interactive Power BI business intelligence solution designed to analyze enterprise sales performance, warehouse operations, customer behavior, and cross-channel analytics.

The dashboard system transforms transactional business data into meaningful insights that support operational monitoring, strategic planning, and executive decision-making.

---

# Dashboards Included

## 1. Executive Overview Dashboard
Provides high-level business KPIs including:
- Revenue growth overview
- Channel revenue share
- Customer vs transaction analysis
- Promotion performance
- Quarterly transaction trends

---

## 2. Sales Manager Dashboard
Focuses on customer and sales performance analysis:
- Revenue target achievement
- Customer value metrics
- Loyalty-level contribution
- Top-selling promotional products
- City sales performance

---

## 3. Warehouse Operations Dashboard
Monitors warehouse efficiency and operational performance:
- Warehouse utilization
- Product distribution by warehouse
- Warehouse revenue trends
- Revenue by warehouse
- Distribution coverage

---

## 4. Cross-Channel Analytics Dashboard
Compares Online and POS sales channels:
- Online vs POS revenue trends
- Product performance comparison
- Promotion revenue comparison
- Customer spending distribution
- Channel revenue efficiency

---

# Key Features
- Interactive dashboards
- KPI comparison cards
- Revenue trend analysis
- Cross-channel sales analytics

# Business Value
This project helps organizations:
- Monitor enterprise sales performance
- Compare online and POS channels
- Track warehouse operations
- Evaluate promotion effectiveness
- Support data-driven decision-making
- Improve strategic planning and operational visibility

---

# Dataset Architecture
The project follows a modern data pipeline architecture:
- Bronze Layer → Raw Data
- Silver Layer → Cleaned & Transformed Data
- Gold Layer → Business-Ready Analytical Dataset
